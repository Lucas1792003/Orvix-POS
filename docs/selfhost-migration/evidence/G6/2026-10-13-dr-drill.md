## Drill tool bugs found (fixed before the evidence run)

1. `umask 077` from `backup-lib.sh` left the init SQL unreadable for the container's `postgres` user → db init failed.
2. Running `globals.sql` with `ON_ERROR_STOP` stops at the first expected `role "anon" already exists`, so later roles
   (`supabase_realtime_admin`) were missing and `pg_restore --exit-on-error` failed. The runbook runs it without
   `ON_ERROR_STOP`, which is correct; keep it that way.
3. GoTrue's admin user list does not embed factors; `/admin/users/{id}/factors` does.
4. A `recovery_target_time` never logs "stopping after commit"; the check now asserts the stop xid and the state.

Findings for the runbook: `email-unpack.py` needs the index under its mail name `<id>.index.json`. A local build
directory stores it as `index.json`, so a restore from a local build has to copy or rename it first. Nothing else
deviated from `restore-from-email.md` §2–§4.
